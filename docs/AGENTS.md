# docs

## Purpose
專案文件目錄。存放功能規格設計文件（specs）與實作計畫文件（plans），用於記錄功能需求分析、UI/UX 設計決策、及開發步驟規劃。所有文件均以日期前綴命名，便於追溯功能演進歷程。

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `superpowers/` | 透過 Superpowers 工作流程產生的規格與計畫文件（見 `superpowers/AGENTS.md`） |

## For AI Agents

### Working In This Directory
- 這個目錄僅存放文件，不含任何可執行程式碼
- 新增功能時在 `superpowers/specs/` 建立 design 文件，在 `superpowers/plans/` 建立 plan 文件
- 文件命名格式：`YYYY-MM-DD-feature-name[-design].md`

### Testing Requirements
無（純文件目錄）
